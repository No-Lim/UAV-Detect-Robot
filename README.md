## 1. 项目简介

`UAV-Detect-Robot` 是一款面向低空黑飞无人机巡检与反制场景的四足机器人系统。项目以四足机器人为移动平台，结合视觉识别、RemoteID 信息抓包、GPS 相对位置解算、云台瞄准与激光指向等模块，实现低空无人机目标的发现、定位、跟踪与指向反制。

本项目针对机场、园区、场馆、重要设施等场景中低空黑飞无人机难以及时发现和快速处置的问题，设计了一套低成本、模块化、可复现的移动式无人机反制原型系统。相比传统固定式反制设备，四足机器人具备更好的复杂地形通过能力，可在草地、坡道、台阶、碎石等非结构化环境中执行移动巡检任务。


## 2. 系统功能

本项目主要实现以下功能：

- 四足机器人基础行走与巡检运动；
- 基于强化学习策略的四足运动控制；
- 开环 IK 步态测试与舵机方向验证；
- IMU 数据读取与姿态定标；
- 低空无人机视觉检测与云台瞄准；
- ESP32-WIFI 嗅探 RemoteID 广播信息；
- 解析无人机 ID、GPS、高度、速度等信息；
- 结合机器人自身 GPS 进行无人机相对位置解算；
- 云台控制与激光指向驱离演示。

---

## 3. 系统总体架构

系统整体由四足机器人运动控制模块、无人机视觉瞄准模块、RemoteID 抓包模块、RID+GPS 解算模块、云台控制模块组成。
